# Afghan Bazaar افغان بازار

Afghan Bazaar

Build Afghan Bazaar, a production-ready marketplace for Afghanistan inspired by Facebook Marketplace and Mudah.my.

Create a premium, fast, secure, and scalable application for Android, iOS, and Web. The app should feel like a real commercial product—not an AI prototype.

Implement secure authentication, user profiles, seller ratings, public seller pages, all 34 Afghan provinces and cities, posting and managing listings, multiple image uploads, favorites, recently viewed, advanced search and filters, real-time chat, push notifications, reporting, and a complete admin dashboard.

Include categories such as Cars, Property, Jobs, Electronics, Mobile Phones, Services, Fashion, Home, Business, Education, Agriculture, Animals, and Others.

Support Dari (default), Pashto, and English with full RTL support.

Use Supabase with Authentication, PostgreSQL, Row Level Security (RLS), Storage, Realtime, and an optimized database architecture.

Generate a complete design system, all screens, navigation, database schema, reusable components, APIs, loading states, error states, empty states, and responsive layouts.

Prioritize simplicity, speed, accessibility, security, maintainability, scalability, and exceptional user experience. Avoid duplicate features, unnecessary complexity, placeholder content, and inconsistent design. Every screen should be polished, intuitive, and production-ready.
